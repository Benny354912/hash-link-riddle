# hash-link-riddle
Ein minimalistisches, clientseitiges Tool zum Erstellen und Teilen von Hash-Challenges. Du gibst eine geheime Eingabe ein - die App erzeugt daraus eine SHA-256-Hash-URL, die du teilen kannst. Wer den Link öffnet, sieht nur das Eingabefeld und muss die richtige Eingabe erraten, die denselben Hash erzeugt. Kein Backend, keine Daten werden übertragen.
